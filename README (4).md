# EV Charging Infrastructure & Demand Analysis

## Project Overview
An end-to-end data analytics project analyzing EV charging sessions to understand charging demand, energy consumption, charging duration, and station performance.

## Tools & Technologies
- Python
- Pandas
- PostgreSQL
- SQL
- Power BI

## Project Workflow
1. Data collection
2. Data cleaning using Python & Pandas
3. Feature engineering
4. Data storage in PostgreSQL
5. SQL-based analysis
6. Interactive Power BI dashboard
7. Business insights

## Key Analysis
- Total charging sessions
- Total energy delivered
- Average energy per session
- Average charging duration
- Charging sessions by station
- Energy delivered by station
- Charging demand over time
- Charging sessions by hour
- Station performance

## Dashboard
The Power BI dashboard provides an interactive view of EV charging demand, energy consumption, charging duration, and station-level performance.

## Project Structure
- `EV_Charging_Analysis.ipynb` — Python data cleaning and analysis
- `charging_sessions_clean.csv` — cleaned dataset
- `EV_Charging_Dashboard.pbix` — Power BI dashboard
- `README.md` — project documentation

## Note
The current demonstration dataset contains a small number of charging sessions, so the dashboard demonstrates the complete analytics workflow and methodology.
